# **App Name**: Gopichand's Portfolio

## Core Features:

- Hero Section: High-impact introduction with a showreel/crash course video.
- Client Showcase: Display a row of top client logos to build credibility.
- Tools and Tech Stack: A structured grid showcasing design and technical skills.
- Selected Works: Display featured case studies with project details and links.
- Impact Statistics: Highlight key achievements and metrics with data visualization.
- Contact Section: Prominent contact buttons for mobile, email, LinkedIn, and Behance.

## Style Guidelines:

- Primary color: Black (#000000) for the background to create a stark, modern feel.
- Background color: Off-black (#080808) with a desaturation of 20% to differentiate it from the black primary, providing better readability for other elements on the page.
- Accent color: Light gray (#D3D3D3) for borders and secondary elements, complementing the primary and background colors for a professional look.
- Headline font: 'Playfair', serif, for headlines; body font: 'PT Sans', sans-serif, for body. Note: currently only Google Fonts are supported.
- Single-page scrollable layout with vertically stacked sections.
- Simple, black/white SVG icons for clients and tools.
- Subtle transition animations when scrolling between sections.
